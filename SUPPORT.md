# Support

Support is best-effort. Wicker Money is pre-1.0 and has a single maintainer.

- **Docs:** start with the docs site at <https://wickermoney.dev>.
- **Questions and ideas:** use GitHub Discussions:
  <https://github.com/wickermoney/wicker-money/discussions>. Suggestions are
  welcome there or through the
  [feature request template](https://github.com/wickermoney/wicker-money/issues/new?template=feature_request.yml).
- **Bugs:** open an issue using the bug report template. Issues are for bugs
  only; please use Discussions for questions.
- **Pull requests:** feature pull requests are not being accepted right now.
  Typo, docs and small bug-fix PRs are fine. See
  [CONTRIBUTING.md](https://github.com/wickermoney/.github/blob/main/CONTRIBUTING.md).
- **Private matters:** email [support@wicker.money](mailto:support@wicker.money).
- **Security vulnerabilities:** do not open an issue. See
  [SECURITY.md](https://github.com/wickermoney/.github/blob/main/SECURITY.md).

Please redact financial data, tokens and secrets from anything you post.
